🏠 Promotion Immobilière – Landing Page

A fully responsive landing page with a modern and user-friendly UI, developed using HTML, CSS, JavaScript, and PHP (for mail sending).
The project is designed for a real estate promotion company, showcasing services, projects, blogs, and contact functionalities.

🚀 Features

🌐 Responsive Design: Works seamlessly on desktop, tablet, and mobile devices.

🎨 Modern & Friendly UI with clean layouts.

📧 Mail Sending with PHP (Contact form integration).

🏗️ Projects Showcase with filtering and individual project pages.

📲 WhatsApp integration for project-specific contact forms.

⚙️ Installation & Usage

Clone the repository:

git clone [https://github.com/yourusername/promotion-immobiliere.git](https://github.com/hamou592/imaar-eldjazair)


Navigate into the project folder:

cd promotion-immobiliere


Open index.html in your browser to view the landing page.

Ensure your server supports PHP.
